Featured project

Christmas Store Parking & Workflow App

This is the project I’m most proud of. It started as a simple way to track vehicles and turned into a real-time workflow system used across multiple volunteer stations.

I built this app to help a church Christmas Store event run more smoothly. Volunteers check families in, track where they are in the process, assign shoppers, manage gift wrapping, and coordinate final delivery back to the car.

HTML SCSS / CSS JavaScript Firebase Real-time sync
  • Built and maintained the entire project independently in my free time.
  • Supports 50+ volunteers and events with 250+ vehicles.
  • Uses Firebase for live, multi-user updates across devices with no refreshing.
  • Tracks the full workflow from check-in to registration, shopping, wrapping, and reindeer delivery.
  • Version 4 added bag tracking, wrapping station assignments, auth, database rules, and better stats.
  • Created four major versions based on feedback from church leaders and volunteers.
